HOW IT WORKS

One break, the whole seam

Nothing here is on a scheduler or a scan loop. The work happens on the break that started it, and the only thing left running afterwards is a timer.

01

You break one block

From there it follows blocks of the same type outward. They do not have to be touching: a gap of two still counts as the same seam. A hard cap keeps one break from running away with the server.

02

The seam pays out at once

The XP lands straight in your bar instead of dropping as orbs. Nothing to walk over, and nobody can run in and scoop it up first. Fortune raises the payout, and you can set Silk Touch to drop the blocks instead.

03

It grows back

Each block remembers its own timer, with a little randomness on top, so a seam comes back in pieces rather than all in one go. Blocks only ever return into empty air. If someone built there in the meantime, nothing gets overwritten.

/veins gui Every change is written to config.yml and applied immediately. No apply button, no reload step, no restart.

THE MENU

The config file, with a lid on it

Everything the plugin does is in here: which blocks count as veins, where they generate, which worlds they apply to, what they pay, and what players see and hear when a seam pops.

Anywhere the menu wants a block, hold that block on your cursor and click. It reads what you are holding rather than making you spell out a material name.

Editing the file by hand still works and the comments in it survive being rewritten. /veins reload picks up changes made on disk.

Exp Veins - config

This is the real menu, with the real items in it. Everything the plugin does sits behind one of these eight buttons. Nothing here needs an anvil or a sign to type into, so a Bedrock player sees what a Java player sees.

VEIN BLOCKS

Any block you like, paying whatever you say

The plugin ships knowing nothing about a particular dimension, generator or server. A vein block is just a material, a payout and a timer.

TWO ROLES

Vein and core

Vein blocks are the bulk of a seam, and they are what generation places. Core blocks are the rare ones buried inside, and they usually pay a lot more. They are the reason to keep digging once you have hit something.

REGROWTH

Each block has its own timer

Every block type sets its own comeback time, and how much that time wanders either side of it. Seams that came due while nobody was nearby return as soon as someone walks back. A restart does not lose the queue.

220

The most one break can pop

A ceiling on how far one break is allowed to spread, so a seam can never run away and drag the server down with it.

2

Blocks apart and still one vein

How far apart two blocks can sit and still count as one vein. Two or three is plenty. Higher numbers make every single break check a lot more blocks.

1.75×

At Fortune III

Fortune adds a bit more per level, and you decide how much. Set it to zero and enchantments stop counting at all.

SILK TOUCH

Blocks instead of XP

Turn it on and Silk Touch drops the vein blocks themselves and pays nothing. They still grow back, so it is never a way to strip a seam permanently.

TOOLS AND WEAR

What it takes to work a seam

Limit seams to certain tools, or leave the list empty and let bare hands work. Durability can cost the usual single point per break, or one point per block, so a forty-block seam actually wears your pickaxe down.

ON DISK

Or skip the menu and edit the file

You name each entry yourself. The material underneath is what players actually swing at. The menu writes this file for you, though there is nothing stopping you writing it by hand.

Height band, weight and cluster size only matter when generation is switched on. A block with no generation section still pops and still regrows.

ONE VEIN BLOCK glow-seam:
  material: LIGHT_BLUE_CONCRETE
  display: "&bGlow Seam"
  xp: 3
  regen-minutes: 60
  regen-jitter-minutes: 10
  role: VEIN
  generation:
    weight: 100
    min-y: -48
    max-y: 40
    cluster-min: 5
    cluster-max: 16

GENERATION

Seams that come with the world

Off until you turn it on. Once it is running, seams get placed into new chunks as they generate. It only ever replaces blocks you have listed as replaceable, so caves, ores and anything a player built stay exactly as they were.

EXPOSED

The cluster has to touch open air, so veins turn up on cave walls and get found by exploring.

BURIED

The cluster must not touch air, so every seam has to be dug out of solid rock.

ANY

No exposure rule at all. Place them wherever the height band and weight allow.

/veins scatter <radius> [force] Existing chunks are never touched. To seed a world that already exists, walk or fly the area and scatter it — each chunk is marked so a second pass cannot double the density.

Scatter will not force-load anything. Doing that on a live server stalls the main thread and every player feels it, so it only seeds the chunks already loaded around you.

PER WORLD

A global setting, and overrides only where you want them

Any world can switch popping and generation on or off by itself, and scale both XP and regrow time to taste. Leave a setting on inherit and that world simply follows your global value.

The world's own entry

Anything set under world-overrides for that world wins outright.

The global list

Otherwise the settings.worlds list decides, which can be read as a whitelist or flipped to a blacklist.

Everywhere

An empty global list means every world on the server.

MULTIPLIERS

Better rates without a rank ladder

A world can pay double and grow back twice as fast. Separately, you can hand a rank a better rate through a permission: the highest veins.multiplier.<number> a player holds is the one that counts. The plugin never has to know what your ranks are called.

Leave a key out of a world override and that world simply follows the global value. The Worlds menu writes the section for you.

WORLD OVERRIDES world-overrides:
  resource_world:
    enabled: true
    generation-enabled: true
    xp-multiplier: 2.0
    regen-multiplier: 0.5
  world_nether:
    enabled: false

Double XP, and back twice as fast.

THE BLOCK EDITOR

Every setting, and the item behind it

One block type, opened up. The same controls appear for every block you add.

Exp Veins - glow-seam

One row holds everything about a single block. Left and right click nudge a number up and down, shift jumps in bigger steps, and middle click lets you type an exact value into chat.

Payout

Straight into the XP bar, or dropped as orbs the vanilla way. Scaled by the world, the player's permissions and Fortune.

Effects

Particles, sounds and the action bar, each switched independently.

Messages

The pop message, wrong tool, no permission and the rest, with %xp%, %blocks% and %vein% to fill in.

Core chance

How often a core block turns up inside a generated cluster.

COMMANDS

Six commands, and one you will actually use

Everything sits under /veins, behind veins.admin.

/veins gui

The live config menu. Everything is in here.

/veins stats

What you have set up, and how many veins are waiting to come back in each world.

/veins scatter

Seeds the chunks loaded around you, once each.

/veins regen

Brings every waiting vein back right now, in one world or all of them.

/veins give

Puts vein blocks in your hand so you can place them yourself.

/veins reload

Re-read config.yml from disk.

veins.admin

The config menu and every subcommand. Operators by default.

veins.mine

Allowed to pop veins for XP. Everyone by default.

veins.multiplier.<n>

An XP multiplier, granted per rank. The highest one a player holds is the one that applies.

Get Exp Veins Unleashed

  1. Drop the jar into plugins/ and start the server.
  2. Run /veins gui and add a block. Nothing pops until you do.
  3. Switch generation on if you want new chunks to carry seams. There is no step four.
